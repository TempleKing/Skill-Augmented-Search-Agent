# Search Recovery

1. Review the last failed query, outcome, and unresolved clue.
2. Inspect a relevant source with `open_document` or locate a distinctive term with `find_in_document` before broadening the search.
3. Determine3. Otherwise determine whether the failed query was too narrow, too broad, or used the wrong alias. Change one meaningful constraint at a time by removing extra words, substituting synonyms, or searching an intermediate entity.
4. Prefer the corpus language and switch only when evidence suggests it.
5. Compare the result with previous evidence and inspect new candidates. Check whether the result establishes the missing relationship.
6. Avoid repeating an identical failed query. Stop when evidence is sufficient or the budget is exhausted.

Never invent missing evidence, documents, or entities.
